NETWORKING GUIDE 018 5 MIN READ

MAC Addresses

Your device has an IP address. But when data travels across a local network, another kind of address helps deliver it over the local link. Let's find out what a MAC address does.

01 / THE QUESTION

Your laptop is connected to Wi-Fi. Your phone is connected too.

Both devices have IP addresses. Imagine your laptop wants to send data to your phone and knows the phone's IP address.

There's another question underneath: what address is used to deliver the data across the local network link?

That's where a MAC address enters the story.

02 / MEET THE MAC ADDRESS

An address for a network interface

MAC stands for Media Access Control. A MAC address is a link-layer address used by network technologies such as Ethernet and Wi-Fi.

In many familiar networks, it helps identify the source and destination interfaces for local delivery. Network switches can use Ethernet source MAC addresses to learn which interfaces are reachable through their ports.

One device, different address types
DEVICE Laptop IP · 192.168.1.10
→
NETWORK INTERFACE Wi-Fi adapter MAC · 3C:52:82:7A:91:4F

Illustrative example only. Actual addresses vary, and devices can use multiple interfaces or configured MAC addresses.

The important word is interface. A computer may have a Wi-Fi interface and a separate Ethernet interface. Each can have a different MAC address.

03 / READING THE FORMAT

What does a MAC address look like?

A common 48-bit MAC address is written as six pairs of hexadecimal digits. Hexadecimal uses the numbers 0–9 and letters A–F.

Example · 48-bit MAC address

3C:52:82:7A:91:4F Six hexadecimal pairs · 48 bits in total

Depending on the operating system or tool, the same address may appear with hyphens or another accepted notation instead of colons.

You don't need to memorize the example. Recognize the format and understand what it represents: a link-layer address associated with a network interface.

Also, don't assume every MAC address is a permanent hardware identity. Devices can use locally administered or randomized addresses, especially for Wi-Fi privacy.

04 / THE INTERFACE MATTERS

Why specify the network interface?

Your laptop doesn't connect to a network by magic. It uses a network interface, such as a Wi-Fi adapter or Ethernet controller.

Wi-Fi

Connects to a wireless network through a wireless access point or router.

Ethernet

Connects to a wired network through an Ethernet cable and compatible network equipment.

A laptop can have both interfaces, and they can have different addresses. The precise question is therefore: “What is the MAC address of the interface I'm investigating?”

05 / LOCAL DELIVERY

Put the addresses back on a network

Imagine a few devices connected to the same local network. When Ethernet frames travel across a LAN, the destination MAC address helps determine which interface should receive a frame on that local link.

Conceptual illustration, not a literal wiring diagram. Wi-Fi communication also uses link-layer addressing, but the details differ from a simple wired Ethernet example.

A switch can learn which MAC addresses appear on which ports and use that information to forward frames. Wireless networks have their own link-layer details, but the same broad idea of local delivery remains useful.

MAC addresses are not used to route packets across the entire Internet. As traffic crosses routers, the link-layer frame is generally replaced for the next network link, while the IP packet is forwarded toward its destination.

06 / IP VS MAC

So, is a MAC address the same as an IP address?

No. They serve different purposes.

MAC ADDRESS

A link-layer address used to identify interfaces for local network delivery.

IP ADDRESS

A logical network-layer address used to identify destinations and route packets between networks.

A simple way to remember the distinction: IP helps get a packet toward the destination network, while link-layer addressing helps deliver the frame across the current local link.

That's a simplified model, but it's a solid starting point for understanding how devices communicate.

STOP & THINK

If a laptop knows another device's IP address, how can it discover the MAC address needed for local IPv4 delivery?

07 / THE NEXT CLUE

How does a device find the MAC address?

We've reached a small networking mystery. A device knows an IP address, but it may still need a link-layer address to deliver data locally.

On a typical IPv4 LAN, ARP — Address Resolution Protocol helps resolve an IPv4 address to a MAC address.

IPv6 uses a different mechanism called Neighbor Discovery rather than ARP. We'll begin with ARP in the next article.

08 / THE SECURITY CONNECTION

Why should cybersecurity analysts care?

MAC addresses can appear in DHCP records, switch tables, wireless logs, packet captures and troubleshooting data. They can help an analyst connect different pieces of network evidence.

01

Which interface or device was associated with this address at that time?

02

Do DHCP, switch or wireless records support that association?

03

Could address randomization, spoofing or a changed network configuration affect the conclusion?

A MAC address alone does not prove who owns a device or who used it. It is one clue, and its meaning depends on the surrounding evidence.

09 / CONNECT THE DOTS

Return to the laptop and phone from the beginning. The laptop wants to send data locally. IP addressing and link-layer addressing play different roles in getting that data to the right place.

The laptop may know the phone's IP address, but local delivery can require resolving that IP address to a link-layer address first.

That missing connection is our next clue: ARP.

TAKEAWAY

A MAC address is a link-layer address used for local delivery. It differs from an IP address, and it should be treated as one piece of network evidence—not a guaranteed permanent identity for a physical device.
